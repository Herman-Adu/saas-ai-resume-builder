# Next steps (sprint ledger)

Active plan: `v0_plans/realistic-map.md` (**approved**). Current sprint: S0 test harness.

Browser tests: `npm run test:smoke`, `test:seo`, `test:axe` (or `test:e2e` for all). They reuse the running dev server on port 3000. In the v0 sandbox Chromium needs system libraries once: `sudo dnf install -y nss nspr atk at-spi2-atk cups-libs libdrm libxkbcommon mesa-libgbm alsa-lib pango libXcomposite libXdamage libXrandr libXfixes`.

CI (`.github/workflows/ci.yml`): `checks` runs typecheck, lint and unit tests with no secrets. `app` builds and runs every browser test (including signed-in) against the shared Neon database. It fails, never skips, if `BETTER_AUTH_SECRET`, `POSTGRES_PRISMA_URL` or `POSTGRES_URL_NON_POOLING` is missing from the GitHub Actions secrets. It runs `prisma migrate status` first, so a PR that adds a migration fails until the migration is applied to the database (db-schema-change skill); CI itself never applies one. Always read the `app` log for real test counts before merging.
