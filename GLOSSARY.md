# Orbit CV

A resume builder where one complete resume is kept and trimmed for each job application, with AI help and paid tiers.

## Resume content

**Resume**:
A saved document made of contact details, a summary, sections of entries, and a chosen template.
_Avoid_: CV, document, profile

**Section**:
A named group of entries on a resume, such as Work experience, Education, Skills, Links, Certifications, Languages or Projects.
_Avoid_: Block, category

**Entry**:
One item inside a section, such as a single job, degree, certification or project.
_Avoid_: Item, record, row

**Bullet**:
One line of achievement or responsibility inside an entry. The smallest unit a user can remove when tailoring.
_Avoid_: Point, description line

**Link**:
A labelled web address on a resume, such as LinkedIn, a portfolio or GitHub.
_Avoid_: URL field, social

## Tailoring

**Master resume**:
The user's one complete resume, marked as such, which holds everything they might ever send. Tailoring starts from it.
_Avoid_: Main resume, base CV, profile

**Tailor**:
To copy a resume and then remove or hide sections, entries and bullets so the copy fits one job.
_Avoid_: Customise, fork, clone

**Tailored resume**:
A copy made by tailoring. It is independent of the master resume once created; later edits to the master do not change it.
_Avoid_: Variant, version, linked resume

**Hide**:
To keep an entry or bullet in the data but leave it off the rendered resume and the PDF, so it can be brought back.
_Avoid_: Disable, archive

## Import

**Import**:
Creating a new resume by uploading a PDF whose text is read into structured sections, entries and bullets.
_Avoid_: Upload resume, parse, sync

**Review**:
The step after an import where the user checks and corrects the extracted content in the normal editor before relying on it.
_Avoid_: Confirm, verify

## Presentation and plans

**Template**:
A visual layout a resume is rendered in. Changing the template never changes the content.
_Avoid_: Theme, design, style

**Plan**:
The subscription level of a user: Free, Pro or Pro Plus. Limits and features are decided by plan in one place.
_Avoid_: Tier, package, subscription type

**Cap**:
The number of base resumes a plan allows (1, 3 or unlimited).
_Avoid_: Quota, allowance
